# Skeleton C

A minimal C project skeleton for quick setup of basic C programs.

## Overview

This repository provides a barebone structure for writing and testing C code without unnecessary boilerplate.

It is designed to help developers quickly start small C programs, experiments, or learning exercises.

## Features

- Simple C project structure
- Minimal boilerplate code
- Easy to compile and run
- Useful for learning and testing concepts

## Files

- `skeleton.c` → Main C source file
- `git.sh` → Helper script (if used for setup or automation)

## Usage

### Compile
```bash
gcc skeleton.c -o app
```

### Run
```bash
./app
```

## Purpose

This project is intended for:

- Learning C programming
- Practicing algorithms
- Quick prototyping
- Testing small code snippets
